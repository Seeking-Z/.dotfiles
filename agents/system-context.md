# 系统环境规范

在环境差异会影响判断或操作时，按已确认计划检查与任务直接相关的系统信息；本机数据的收集边界遵循 [`secrets-and-privacy.md`](secrets-and-privacy.md)。

## 按需检查

- 操作系统和发行版、内核版本及处理器架构。
- 当前登录 shell 与实际运行的 shell；涉及桌面配置时，再检查桌面环境、显示协议和相关会话信息。
- 与改动有关的工具、版本、包管理器和服务管理器是否可用。
- 任务目标主机是否与当前执行环境相同；若无法确定，先询问，不要假设。
- 查询系统事实时，优先选择只返回所需字段的命令或选项。若工具会同时采集本机标识、凭据或无关私人数据，改用更窄的方法；找不到安全方法时暂停并询问。

## 收集边界

- 只收集能影响当前任务的信息，不转储完整环境变量、进程列表或无关的主机信息。
- 不得为识别环境而扩大收集范围。
- 记录系统信息时只写必要结论。通用系统事实可以按需记录；不要写入本机用户名、主机名、私人绝对路径、网络地址、序列号或唯一设备标识。任务文件引用优先使用仓库相对路径。
- 命令输出与预期环境不符时，暂停依赖该假设的步骤并更新计划。
