# 系统环境规范

在环境差异会影响判断或操作时，检查与任务直接相关的系统信息，并在计划获准后再检查。

## 按需检查

- 操作系统和发行版、内核及处理器架构。
- 当前登录 shell 与实际运行的 shell；涉及桌面配置时，再检查桌面环境、显示协议和相关会话信息。
- 与改动有关的工具、版本、包管理器和服务管理器是否可用。
- 任务目标主机是否与当前执行环境相同；若无法确定，先询问，不要假设。

## 收集边界

- 只收集能影响当前任务的信息，不转储完整环境变量、进程列表或无关的主机信息。
- 不读取密钥、凭据文件或无关个人文件来推断系统情况。
- 记录系统信息时只写必要结论；不要把用户名、主机名、路径等个人或机器标识写入通用规范。
- 命令输出与预期环境不符时，暂停依赖该假设的步骤并更新计划。
